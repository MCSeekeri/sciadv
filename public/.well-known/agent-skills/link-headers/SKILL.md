# Link Headers

This site advertises agent-readable entry points from the homepage response headers.

- Homepage: `https://lib.sci-adv.org/`
- Skills index: `https://lib.sci-adv.org/.well-known/agent-skills/index.json`
- RSS feed: `https://lib.sci-adv.org/rss.xml`
- About page: `https://lib.sci-adv.org/about/`

The homepage returns RFC 8288 `Link` headers so agents can discover these resources without parsing HTML.
